## Description (en)
Mody lets developers and testers change HTTP traffic right in the browser — no proxy needed.

• Request & response headers — add, override, append or remove any header
• Redirect URLs — regex rules with capture groups ($1, $2 …)
• Content-Security-Policy editor with live preview and parser
• Cookie append for outgoing requests
• Profiles — keep separate setups (local, staging, production…) and switch in one click; mark profiles "always on"
• Filters — limit changes to URL patterns, request / excluded domains, HTTP methods, resource types, specific tabs, tab groups or windows, or an auto-off timer
• Undo, clone, sort, import / export as JSON
• Cloud sync through your own Chrome account (chrome.storage.sync): compressed snapshots, automatic or confirm-before-apply, restore any of the last 20 versions
• Pause everything with one click, from the toolbar context menu or a keyboard shortcut
• Light & dark themes

Privacy first: Mody has no analytics, no ads, no account, and never sends your data anywhere. Rules are applied by Chrome's declarativeNetRequest engine.

## Description (zh_CN)
Mody 让开发和测试同学直接在浏览器里修改 HTTP 流量，无需代理。

• 请求头 / 响应头：新增、覆盖、追加、删除任意 header
• URL 重定向：正则规则，支持 $1、$2 等分组引用
• Content-Security-Policy 编辑器，实时预览并支持解析
• 为请求追加 Cookie
• 多配置（Profile）：本地、测试、线上等环境独立保存，一键切换；可设置"始终生效"
• 过滤器：按 URL 正则、请求域名 / 排除域名、HTTP 方法、资源类型、指定标签页 / 标签组 / 窗口限定生效范围，或设定自动关闭时间
• 撤销、克隆、排序，JSON 导入导出
• 通过你自己的 Chrome 账号云同步（chrome.storage.sync）：压缩快照、自动同步或确认后应用，可回滚最近 20 个版本
• 一键暂停：工具栏按钮、右键菜单或快捷键
• 亮色 / 深色主题

隐私优先：Mody 没有任何统计、广告和账号体系，不会把你的数据发送到任何地方。规则由 Chrome 内置的 declarativeNetRequest 引擎执行。
